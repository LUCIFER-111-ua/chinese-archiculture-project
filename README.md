# 中国古代建筑文化展示

基于 Vue 3 + Three.js 的中国古代建筑 3D 展示项目。

## 在线预览

https://peace-and-joy.top

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 部署到 GitHub Pages
npm run deploy
```

## 技术栈

- Vue 3
- Three.js
- Vite
- GSAP
